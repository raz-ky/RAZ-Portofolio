# ROCKY — Color Motion

A colorful cinematic portfolio built with React + TypeScript + Vite + Tailwind CSS + GSAP + ScrollTrigger + Lenis.

## Run

1. Install Node.js 20.19+ or 22.12+.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:

npm install
npm run dev

5. Open the local URL printed by Vite.

## Production

npm run build
npm run preview

## Customize

- Projects/photos: `src/data/portfolio.ts`
- Background effects: `src/components/CinematicBackground.tsx`
- Main styling: `src/index.css`
- Components: `src/components/`
- Custom background video: `public/videos/rocky-neon-bg.mp4`

The video is optional. If you add it, keep the filename exactly `rocky-neon-bg.mp4`.
